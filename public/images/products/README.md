# Product Images Folder

## Instructions for Adding Product Images

Add your product images to this folder with the following names:

### Required Image Names:

1. **rice.jpg** or **rice.png** - Rice (PDS) product image
2. **wheat.jpg** or **wheat.png** - Wheat Flour (Atta) product image
3. **sugar.jpg** or **sugar.png** - Sugar product image
4. **toor-dal.jpg** or **toor-dal.png** - Toor Dal product image
5. **cooking-oil.jpg** or **cooking-oil.png** - Cooking Oil product image

### Image Specifications:

- **Format**: JPG, PNG, or WEBP
- **Recommended Size**: 400x400 pixels (square)
- **Max File Size**: 500 KB per image
- **Aspect Ratio**: 1:1 (square) for best display

### Example:
```
/public/images/products/
  ├── rice.jpg
  ├── wheat.jpg
  ├── sugar.jpg
  ├── toor-dal.jpg
  └── cooking-oil.jpg
```

### Notes:
- Images will be displayed in the Product Inventory table
- Use clear, high-quality images with good lighting
- Consider using product images with a white or transparent background
- The system will automatically fallback to placeholder images if files are not found
